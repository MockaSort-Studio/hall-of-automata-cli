# Crew automaton body

Assembly combines safety, the compact persona in `agents/roster.json`, shared
Crew discipline, a validated role prompt, and the bounded assignment.

`roles.json` supplies reusable role tools. `roster.json` supplies
automaton-specific domain operation additions. Their assembled `actor.tools`
set is the policy source for the worker environment profile; it does not
install, verify, or activate an Armory suite by itself.
